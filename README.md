# SajuStep · 사주스텝

사주를 외우는 것이 아니라 읽을 수 있게 만드는 모바일 중심 명리 학습 웹앱입니다.

## 현재 MVP

- 홈: 레벨, 숙련도, 정답률, XP, 추천 학습
- 문제 풀이: 4지선다, 적응형 출제, 최근 문제 반복 억제
- 해설: 핵심 의미, 정답 근거, 보기 비교
- 개념 사전: 음양오행, 천간, 지지, 십성, 합충형파해
- 리포트: 영역별 성취와 혼동 개념
- 마이: 내 출생정보 등록 및 원국 자동 계산
- 귀인지도: 주변 사람 직접 등록, 관계 흐름과 근거 확인
- 해설 피드백 및 로컬 관리자 조회
- 비로그인 학습 기록 저장
- PWA 및 버전 자동 확인

## 실행

별도 설치 없이 `index.html`을 정적 웹 서버로 열면 됩니다.

```bash
python3 -m http.server 8000
```
